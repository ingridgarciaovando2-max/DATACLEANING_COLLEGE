<p>This python solution converst firts and last names from uppercase to lowercase. it also allows names or surnames lacking accents to have them added.</p>
<hr />
<h2>Documentation</h2>
<ol>
   <li>(dataset_diccionario.csv) - conjunto de nombres y apellidos extraidos del dataset_original para comparacion</li>
   <li>(dataset_normalizado.xlsx) - conjunto resultante con nombres y apellidos normalizados con acentos </li>
   <li>(dataset_original.xlsx) - conjunto de datos originales con errores en Mayusculas, apellidos sin acentos </li>
   <li>(normalizacion_copia.py) - codigo para limpieza y normalizacion del conjunto de datos </li>
   <li>(readme.txt) - lista de librerias necesarias para funcionamiento </li>
</ol>
